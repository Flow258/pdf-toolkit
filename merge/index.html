Merge PDF files

Join PDFs into a single document. Drag files to set the order.

How to use this tool

  1. Choose or drop two or more PDF files.
  2. Drag the files into the order you want.
  3. Click Merge PDFs and download the result.

Good to know

Is there a limit on how many PDFs I can merge?

There is no fixed limit. The practical limit is your device memory, so very large batches may be slow on phones.
