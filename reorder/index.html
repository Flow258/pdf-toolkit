Reorder PDF pages

Drag pages to a new position. On touch screens, use the arrow buttons.

How to use this tool

  1. Choose or drop a PDF file.
  2. Drag pages into a new order, or use the arrow buttons on each page.
  3. Click Save new order and download the result.

Good to know

Can I reorder pages on my phone?

Yes. Dragging is for mouse and trackpad, so on a touch screen use the arrow buttons under each page.
